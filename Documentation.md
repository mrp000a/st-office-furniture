# Design System Spec

## 1. Brand & Aesthetic

- **Core Vibe:** Clean, minimalist, highly professional, dark-mode first.
- **Keywords:** Accessible, fast, reliable, modern.

## 2. Color Palette

- **Primary (Indigo):** `#4F46E5` (Used for primary CTA buttons, active states)
- **Secondary (Slate):** `#64748B` (Used for sub-navigation, secondary text)
- **Background Dark:** `#0F172A`
- **Card Background:** `#1E293B`

## 3. Typography & Spacing

- **Scale:** Use a strict 4-pixel grid system for spacing.
- **Heading 1:** `font-size: 2.25rem`, `font-weight: 800`, `letter-spacing: -0.05em`.
- **Body Text:** `font-size: 1rem`, `font-weight: 400`, color is Slate-200.

## 4. Components & Layout Rules

- **Buttons:** Rounded corner radius `8px` (`rounded-lg`). Hover state brightens background color by 10%.
- **Cards:** Border `1px solid #334155`, shadow `shadow-xl`.
- **Grid Layout:** 12-column desktop grid with a maximum content width of `1280px`.
- **Accessibility:** Ensure all color combinations hit a minimum contrast ratio of 4.5:1 (WCAG AA).
